# 📝 To-Do List App

A simple and responsive To-Do List web application built using **HTML**, **CSS**, and **JavaScript**. This project helps users track their daily tasks, mark them as complete, and stay organized.

---

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 📱 Responsive design for mobile and desktop

---

## 🎯 Purpose

This project was built as part of my personal journey. It demonstrates my foundational skills in JavaScript DOM manipulation, event handling, and clean UI design.

---

## 🛠 Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & Responsiveness
- **JavaScript (ES6+)** – Functionality & Logic
